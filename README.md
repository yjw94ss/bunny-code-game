# 🥕 小兔子采萝卜 · 儿童编程闯关

一个给 4 岁小朋友玩的网页编程游戏：用积木给兔子排路线，吃完所有胡萝卜再回小屋。

单文件、零依赖，打开 `index.html` 即可游玩。

## 玩法

1. 点右侧按钮，把积木放进「路线」区
   - 🔵 **前进**：往前走一格
   - 🟠 **左转 / 右转**：原地转向
   - 🟣 **跳跃**：向前跳两格（第 5 关解锁，可以跳过石头）
2. 点「开始」，小兔子按积木顺序一步步执行
3. 吃完**所有**胡萝卜，再走到小屋才通关；提前回家门不会开
4. 积木点一下即可删除，或使用「撤销 / 清空」

## 关卡

10 个手工关卡，最少指令数从 4 块递增到 17 块，逐步引入转向、绕障、多目标与跳跃。

每关记录最优步数，据此给 1~3 星；通关进度与星级保存在浏览器本地（localStorage）。

地图字符：`.` 草地、`#` 石头、`C` 胡萝卜、`S` 起点、`H` 家。改 `index.html` 里的 `LEVELS` 即可加关。

## 给 4 岁做的取舍

- 大按钮、颜色区分明确，不依赖识字
- 即时音效与动画反馈（Web Audio 合成，无外部音频文件，可静音）
- 撞墙只做轻微抖动 + 提示，不判失败重来
- 集齐胡萝卜后小屋发光升旗，给到明确的正反馈
- 手机 / 平板 / 桌面自适应

## 开发工具

`tools/solve.py` 用 BFS 验证每关可解并计算最优指令数，`tools/solutions.json` 是各关最优解，用于回归测试。

```bash
python3 tools/solve.py
```
