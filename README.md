# 🥕 小兔子采萝卜 · 儿童编程闯关

一个给 4 岁小朋友玩的网页编程游戏：用积木给小兔子排路线，吃完所有胡萝卜再回小屋。

单文件、零依赖，打开 `index.html` 即可游玩，也可直接部署到 GitHub Pages。

## 玩法

1. 点右侧按钮，把积木放进「路线」区
   - 🔵 **前进**：往前走一格
   - 🟠 **左转 / 右转**：原地转向
   - 🟣 **跳跃**：向前跳两格，可以越过石头和水塘
   - 🟪 **重复×2**：开一个紫色框，放进去的积木会做两遍
2. 点「开始」，小兔子按积木顺序一步步执行
3. 吃完**所有**胡萝卜，再走到小屋才通关；提前回家门不会开
4. 积木点一下即可删除，或使用「撤销 / 清空」

## 关卡里的机关

| 机关 | 说明 |
| --- | --- |
| 🪨 石头 | 走不过去，可以跳过去 |
| 🌊 水塘 | 走进去会失败，只能跳过去 |
| 🧊 冰面 | 踩上去会**一直滑到尽头**，滑不动了才停；顺路会把萝卜吃掉 |
| 🟠 弹簧板 | 踩上就**自动往前弹两格**，不花积木；前面挡着会弹不动 |
| 🔴 按钮 + 🌉 桥 | 踩一下按钮，断桥才会变成木桥；没按之前桥和门一样跳不过去 |
| 🔑 钥匙 | 走过去自动捡起，门才会打开 |
| 🚪 门 | 锁着时过不去，跳也跳不过（门太高），拿到钥匙后自动打开 |
| 🌀 传送门 | 两个紫色圈圈成一对，踩进去会从另一个出来，方向不变 |

26 个手工关卡，按「走和转 → 跳跃 → 水塘 → 冰面 → 弹簧 → 钥匙门 → 传送门 → 按钮桥 → 重复」递进。
每关记录最优步数，据此给 1~3 星；通关进度与星级保存在浏览器本地（localStorage），按关卡名保存，加减关卡不会错位。

## 关于「重复」

点「重复×2」会生成一个紫色框，之后加的积木都会放进框里；点框里的「✓ 收好」结束编辑。
运行时框里的积木会**整段执行两遍**，所以长路线可以只用很少的积木搭出来。
「重复积木」「重复转弯」两关的积木上限被刻意收紧，只有用重复才够用。

## 加关卡

改 `index.html` 里的 `LEVELS` 数组即可。地图字符：

| 字符 | 含义 | 字符 | 含义 |
| --- | --- | --- | --- |
| `.` | 草地 | `#` | 石头 |
| `C` | 胡萝卜 | `S` | 起点 |
| `H` | 家 | `~` | 水塘 |
| `*` | 冰面 | `^` | 弹簧板 |
| `B` | 按钮 | `=` | 桥（按下按钮前是坑） |
| `K` | 钥匙 | `D` | 门 |
| `1` `2` | 传送门（成对） | | |

关卡字段：`dir` 初始朝向、`best` 最优积木数（决定三星线）、`jump` 是否给跳跃、`repeat` 是否给重复块、`max` 手动指定积木上限。

## 开发工具

- `tools/design.py`：用 BFS 验证每关可解并算出最优指令数，输出 `tools/programs.json`（各关最优解，用于回归测试）。
- `tools/check.py`：关卡体检。检查最优解是否真的踩到冰面/弹簧/按钮，以及「水塘必须跳、门必须钥匙、桥必须按钮、传送门必须传送」——防止设计出可以绕过去的关卡。
- `tools/probe.py`：临时试关卡（读一个 JSON 候选列表，打印每张图的最优步数与路线）。

```bash
python3 tools/design.py    # 验证 + 生成最优解
python3 tools/check.py     # 机制必需性体检
```
