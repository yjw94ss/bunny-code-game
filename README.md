# 🥕 小兔子采萝卜 · 儿童编程闯关

一个给 4 岁小朋友玩的网页编程游戏：用积木给小兔子排路线，吃完所有胡萝卜再回小屋。

单文件、零依赖，打开 `index.html` 即可游玩，也可直接部署到 GitHub Pages。

## 玩法

1. 点右侧按钮，把积木放进「路线」区
   - 🔵 **前进**：往前走一格
   - 🟠 **左转 / 右转**：原地转向
   - 🟣 **跳跃**：向前跳两格，可以越过石头和水塘
   - 🟪 **重复×2**：开一个紫色框，放进去的积木会做两遍
2. 点「开始」，小兔子按积木顺序一步步执行
3. 吃完**所有**胡萝卜，再走到小屋才通关；提前回家门不会开
4. 积木点一下即可删除，或使用「撤销 / 清空」

## 关卡里的机关

| 机关 | 说明 |
| --- | --- |
| 🪨 石头 | 走不过去，可以跳过去 |
| 🌊 水塘 | 走进去会失败，只能跳过去 |
| 🔑 钥匙 | 走过去自动捡起，门才会打开 |
| 🚪 门 | 锁着时过不去，跳也跳不过（门太高），拿到钥匙后自动打开 |
| 🌀 传送门 | 两个紫色圈圈成一对，踩进去会从另一个出来，方向不变 |

18 个手工关卡，按「走和转 → 跳跃 → 水塘 → 钥匙门 → 传送门 → 重复」递进。
每关记录最优步数，据此给 1~3 星；通关进度与星级保存在浏览器本地（localStorage）。

## 关于「重复」

点「重复×2」会生成一个紫色框，之后加的积木都会放进框里；点框里的「✓ 收好」结束编辑。
运行时框里的积木会**整段执行两遍**，所以长路线可以只用很少的积木搭出来。
第 16、17 关的积木上限被刻意收紧，只有用重复才够用。

## 加关卡

改 `index.html` 里的 `LEVELS` 数组即可。地图字符：

| 字符 | 含义 | 字符 | 含义 |
| --- | --- | --- | --- |
| `.` | 草地 | `#` | 石头 |
| `C` | 胡萝卜 | `S` | 起点 |
| `H` | 家 | `~` | 水塘 |
| `K` | 钥匙 | `D` | 门 |
| `1` `2` | 传送门（成对） | | |

关卡字段：`dir` 初始朝向、`best` 最优积木数（决定三星线）、`jump` 是否给跳跃、`repeat` 是否给重复块、`max` 手动指定积木上限。

## 开发工具

`tools/design.py` 用 BFS 验证每关可解、算出最优指令数、并检查「水塘必须跳 / 门不能绕 / 传送门必需」等设计约束；`tools/programs.json` 是各关最优解，用于回归测试。

```bash
python3 tools/design.py
```
